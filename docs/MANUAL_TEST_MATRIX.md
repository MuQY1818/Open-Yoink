## 测试数据与安全规则

1. 使用临时目录和无敏感内容的样例文件：纯文本、PNG、PDF、空文件夹，以及三个同名但内容不同的文件。
2. 每轮前记录原文件路径与校验值；涉及 `⌘` 托管移动时，同时确认原位置、废纸篓和 OpenYoink 托管目录。
3. 普通拖入、移除卡片或拖出，不得删除外部原文件。
4. 普通直接文件拖出最多显示“目标已接受”；托管移动只有在 file promise 完成回调后才能显示“已交付”。
5. 失败后确认卡片、原文件或应用持有的恢复副本至少存在一份。无法确认所有权的文件不得被自动清理。
6. 每个场景分别验证拖出策略：保留、移除、每次询问。取消拖出不应显示错误或移除卡片。

## 发布门槛

- 自动化测试与静态分析全部通过，且无跳过项。
- Finder、Safari、Mail、Notes、一个 Chromium 浏览器和一个常用编辑器的核心路径全部通过。
- 多显示器、Space、全屏与热插拔场景无窗口丢失。
- 所有失败项完成分级；文件安全或数据恢复失败一律阻止发布。
- Sparkle appcast、GitHub Release 资产和匿名下载校验通过。
- 社区版继续采用 GitHub + ad-hoc 分发，不引入付费证书、新账号或新敏感权限。

## 自动化覆盖说明

`OpenYoinkUITests` 当前负责空暂存架、设置导航和核心无障碍审计；单元测试覆盖传输状态、file promise、多选键盘逻辑、持久化、托管移动事务与恢复。上面的真实应用组合仍必须手工执行，不能仅凭自动化测试结果标记为通过。
