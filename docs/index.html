一个随叫随到的暂存架

开始拖拽，它就出现；用完，它自己收起来。
📥

几乎什么都能拖入

文件、文件夹、文本、富文本、图片、链接，连邮件、日历事件、联系人也会自动物化成正规文件。

🚀

拖到任何地方

fileURL + file promise 双表示，浏览器上传区也能用；拖到 Finder 永远只复制，原文件纹丝不动。

⚡️

需要时它就在

一拖自动出现，也可用边缘拉环、⌘⇧Space（双击存剪贴板）或摇动唤出，还能按应用忽略。

🧺

不添乱

高度贴合内容，空了自己收起；Quick Look、多选、Stack、框选、最近项目，全都顺手。

🖥

跟着你的工作区走

多屏、多 Space、全屏应用都适配；可贴左右缘或自由摆放，中英文界面。

🔒

隐私优先

App Sandbox、无统计上报；唯一的联网是更新检查（Sparkle 签名分发，可在设置关闭）。

看一眼就会用

从文件管理器拖到暂存架，再拖到目标位置。

安装

两种方式，任选其一。

Homebrew（推荐）

brew install --cask muqy1818/tap/openyoink

brew 安装不触发 Gatekeeper 弹窗，装完直接能用。

DMG 手动安装

从 Releases 下载 DMG，把 OpenYoink 拖进 Applications。首次打开在终端执行一次：

xattr -dr com.apple.quarantine /Applications/OpenYoink.app
