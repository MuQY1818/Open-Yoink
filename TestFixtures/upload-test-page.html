Open-Yoink Drag-Out Test Page / 拖出测试页

Drag items from the Open-Yoink shelf into the zones. Nothing is uploaded anywhere. 把 shelf 里的项目拖到下面各区域即可，本页不联网。

1. File Upload Zone / 文件上传区

Drop files here（模拟上传区） Accepts files — checks DataTransfer.files（fileURL 映射或 file promise 任一成功即可）

2. Type Inspector / 表示层检查器

Drop anything here to inspect advertised types 显示 e.dataTransfer.types 与 items（对照 Open-Yoink 应广播的表示）

3. Rich Text Zone / 富文本区

Drop a text item here — 文本项应插入到此处

4. Plain Text Area / 纯文本框
