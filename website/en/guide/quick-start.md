# Quick start

1. Drag a file from Finder or another app. OpenYoink appears at the configured screen edge.
2. Drop the file on the shelf, then switch windows or Spaces.
3. Drag the card from OpenYoink to its final destination.

Press `⌘⇧Space` to show or hide the shelf. Press the shortcut twice to hold the current clipboard contents.

An ordinary drag keeps a bookmark to the original file. Holding `⌘` while dropping enables the managed-move workflow; read [File safety](./file-safety) before using it.
