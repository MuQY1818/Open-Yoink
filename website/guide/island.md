# OpenYoink Island <Badge type="tip" text="v1.4.1" />

OpenYoink Island 把 Mac 顶部中央区域变成一个轻量入口。它可以承接拖放，也可以显示传输、计时器、电池和正在播放。

![正在播放时的紧凑 Island，与物理刘海融为一体](/screenshots/island-compact-media.png)

## 开启 Island

全新安装默认启用 Island；前往“设置 → 通用”可以随时关闭。旧用户升级后不会覆盖已经保存的选择，原来的侧边位置和显示习惯保持不变。

你可以分别控制：

- 是否启用 Island
- 是否启用侧边暂存架
- Island 中是否展示暂存架模块
- 计时器、电池与正在播放模块
- 是否允许悬停展开

## 展开与收起

| 操作 | 结果 |
|---|---|
| 点击紧凑 Island | 展开当前模块 |
| 把文件拖近屏幕顶部中央 | 直接展开暂存架模块 |
| 点击紧凑态播放 / 暂停区域 | 直接控制媒体，不必展开 |
| 点击专辑图或活动摘要 | 展开对应模块 |
| 点击展开态顶部中央区域 | 收起 |
| 按 `Esc` 或点击外部 | 收起 |
| 点击固定按钮 | 保持展开 |

拖入项目后，Island 默认保持展开，方便切换目标窗口后继续拖出。

## 有刘海与无刘海屏幕

- 有物理刘海：紧凑内容分布在摄像头区域左右两翼，黑色轮廓与屏幕顶边相连。
- 外接显示器或无刘海 Mac：显示菜单栏下方的顶部悬浮胶囊。
- 跨屏拖拽：Island 会跟随当前拖拽所在的屏幕。

透明窗口区域不会阻挡菜单栏；只有实际可见的 Island 区域参与点击和拖放。

## 与侧边暂存架一起使用

Island 与侧边暂存架不是二选一。它们可以同时开启，并共享 `ShelfStore` 中的暂存内容。侧边快捷键只控制侧边暂存架；Island 的入口和模块选择独立工作。
