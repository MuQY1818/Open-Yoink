# 快捷键

## 全局快捷键

| 快捷键 | 操作 |
|---|---|
| `⌘⇧Space` | 显示或隐藏当前配置的暂存架入口 |
| 连按两次 `⌘⇧Space` | 暂存当前剪贴板内容 |

可以在“设置 → 触发”中修改全局快捷键。

## 暂存架内

| 按键 | 操作 |
|---|---|
| 方向键 | 移动键盘焦点 |
| `Space` | Quick Look |
| `Return` | 打开所选项目 |
| `⌘C` | 复制所选项目 |
| `Delete` | 从暂存架移除 |
| `Esc` | 取消选择、关闭展开的 Stack 或收起 Island |

键盘焦点与多选状态是两个概念：有明确选择时，批量操作作用于选中项目；没有选择时，部分键盘操作会作用于当前焦点项目。
