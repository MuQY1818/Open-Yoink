# 免费开源的 macOS 拖拽暂存架

OpenYoink 是一款免费、开源、本地优先的 macOS 拖拽暂存架。它解决的是一个很具体的问题：当目标窗口暂时不在眼前时，不必一直按住鼠标，也不必先重新排列所有窗口。把文件、文件夹、图片、文本或链接放进 OpenYoink，切换到目标应用后再继续拖出即可。

项目使用 SwiftUI 与 AppKit 编写，源代码以 MIT License 发布，不需要账号，没有订阅，也不包含行为分析。当前版本支持 macOS 15、Apple Silicon 与 Intel Mac。

## 哪些场景适合使用拖拽暂存架？

### 在 Finder 与浏览器之间搬文件

上传附件或图片时，网页往往盖住 Finder。先把文件拖进 OpenYoink，打开目标网页，再从暂存架拖进上传区域，可以把一次容易中断的长拖拽拆成两个短步骤。

### 跨 Space 或全屏应用拖放

当源窗口和目标窗口位于不同 Space，或者其中一个应用处于全屏状态时，持续拖住文件切换桌面并不轻松。OpenYoink 会保留临时内容，让你先松开鼠标，再从目标桌面继续。

### 收集多份素材后统一处理

你可以把来自 Finder、浏览器和其他应用的多个项目放在同一个暂存空间中，完成选择后再逐个拖出、批量复制路径或在访达中定位。

### 利用 Mac 刘海显示轻量活动

OpenYoink Island 可以与带刘海 Mac 的摄像头区域融合，并提供暂存架、传输、专注计时、电池和正在播放等模块。无刘海屏幕或外接显示器会使用顶部悬浮胶囊；不喜欢 Island 时，也可以只保留经典侧边暂存架。

## OpenYoink 与剪贴板有什么不同？

| 方式 | 更适合做什么 | 是否保留原始拖拽语义 |
|---|---|---|
| 系统剪贴板 | 复制文字或少量文件 | 否，主要通过复制和粘贴完成 |
| OpenYoink 暂存架 | 跨窗口、Space 和应用继续拖放 | 是，可以重新拖到支持放置的目标 |
| 普通 Finder 文件夹 | 长期整理和保存文件 | 是，但需要先决定保存位置 |

OpenYoink 不是云盘，也不是长期文件管理器。它更像一个临时落脚点：内容仍然由你决定何时放入、拖向哪里以及何时移除。

## 侧边暂存架与 Island 可以独立使用

经典侧边暂存架和 OpenYoink Island 是两个独立入口，但可以共享同一组暂存内容。你可以：

- 只开启侧边暂存架，用屏幕左侧或右侧完成拖放；
- 只开启 Island，把 Mac 顶部用作信息中心；
- 同时开启两者，从最顺手的入口访问同一批内容；
- 在 Island 中关闭暂存架模块，同时继续使用侧边架。

具体设置方法见[侧边暂存架](./classic-shelf)与[OpenYoink Island](./island)。

## 数据与文件都留在本机

OpenYoink 不要求注册账号，也不会把暂存内容上传到服务器。应用只会在完成拖放、预览或文件承诺交付所必需的范围内访问本机内容。普通拖入通常保留原文件引用；只有明确的托管移动等操作才会创建由应用管理的副本。

在处理重要文件前，建议阅读[文件安全与隐私](./file-safety)，了解普通引用、物化文件和托管移动之间的区别。

## 与 Yoink、Dropover 等产品的关系

OpenYoink 是独立的社区开源项目，与商业应用 Yoink、Dropover 及其开发者没有隶属关系。它面向正在寻找免费、开源 macOS 拖拽工具的用户，但不会复制或冒充这些产品。名称和项目说明中的相关提及仅用于解释使用场景与产品类别。
